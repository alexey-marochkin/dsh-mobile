# DSH Mobile

Русская редакция Developer OS для управления DeepSeek Harness с телефона. Откройте на телефоне рабочее пространство с компьютера, продолжите диалог с агентом и ответьте на его запрос. Сессии и инструменты остаются на компьютере.

[Страница в каталоге Developer OS](https://devos.aicent.ru/dsh-plugins/dsh-mobile/) · [English](README.en.md) · [简体中文](README.zh-CN.md)

## Как выбрать язык

На Android приложение использует системный язык телефона. Для русского интерфейса выберите русский в настройках Android. Панель плагина использует язык интерфейса DSH. В браузере страницы сопряжения и повторного входа учитывают сохранённый язык DSH и языковые предпочтения браузера.

Перевод входит в исходники этого форка. Для проверки изменений нужны плагин и приложение, собранные из этой версии. Ссылки на npm и APK в исходных руководствах ведут к выпускам оригинального проекта.

## Подключение по Wi-Fi

1. Запустите DSH с плагином на компьютере. Подключите телефон и компьютер к одной доверенной сети.
2. В панели мобильного доступа на компьютере выберите локальную сеть, включите доступ и создайте QR-код сопряжения.
3. Откройте приложение на телефоне, выберите подключение по локальной сети и отсканируйте код. Если камера недоступна, вставьте ключ из панели DSH.
4. Выберите компьютер и откройте существующую сессию. Доступ потерянного телефона можно отозвать в списке устройств на компьютере.

## Подключение через интернет

Для собственного VPS выберите в панели удалённого доступа FRP и подключение к существующему серверу. Администратор выдаёт адрес сервера, управляющий порт, токен и публичный HTTPS-адрес. В режиме с публичным сертификатом понадобится также HTTP-порт виртуального хоста FRP. После проверки подключения создайте QR-код для удалённого доступа и отсканируйте его из соответствующего раздела приложения. Проверьте сессию на телефоне через мобильную сеть.

Компьютер с агентом должен оставаться включённым. У каждого сопряжённого устройства есть доступ к сессиям DSH. Храните токены и ключи сопряжения отдельно от репозитория.

[Подключение к существующему FRP](docs/ATTACH_EXISTING_FRPS.en.md) · [Другие способы подключения](README.en.md#connection-guide)

## Сборка из исходников

Для плагина потребуется Node.js версии, указанной в package.json. В корне репозитория выполните:

```sh
npm ci --registry=https://registry.npmjs.org --replace-registry-host=always
npm run typecheck
npm run build
npm pack
```

Архив плагина предназначен для установки в профиль DSH. В DSH Desktop плагины управляются через раздел плагинов приложения. У DSH Web отдельный профиль.

Для Android откройте каталог `apps/mobile/android` в Android Studio либо используйте Gradle Wrapper. Пример для Windows — отладочная сборка с локальной сетью и FRP:

```powershell
cd apps/mobile/android
.\gradlew.bat -PirohNative=false :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Для варианта с iroh потребуются дополнительные Rust- и NDK-компоненты. [Сборка Android и варианты приложения](apps/mobile/README.md)
